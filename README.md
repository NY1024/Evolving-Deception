# Evolving Deception: When Agents Evolve, Deception Wins

## Overview

This repository contains the dataset and codebase for the paper **"Evolving Deception: When Agents Evolve, Deception Wins"**. It provides the experimental data to reproduce or further investigate the phenomenon of deceptive behaviors emerging during the evolution of autonomous agents.

## Repository Structure

```
.
├── dataset.csv    # The experimental dataset containing the evolution data and agent interactions
└── paper/         # Directory containing the assets for the paper
```

## Usage

Researchers can use this dataset to analyze the conditions under which AI agents develop deceptive strategies to maximize their reward functions, as discussed in the paper.
